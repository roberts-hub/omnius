Frequently asked questions.

What's included? +

The SPECTRE Signature LUT (.cube), a One-Click LUT that applies the full look in a single click, the complete node tree setup (PowerGrade) for DaVinci Resolve with versions for Sony, Canon, Fuji and DJI, an in-depth video tutorial on how to use it correctly, and Log practice footage to follow along.

What cameras does it work with? +

Any camera. The node tree is camera-agnostic, and versions for Sony, Canon, Fuji and DJI are included.

Which editing software does it work with? +

The node tree (PowerGrade) is built for DaVinci Resolve — Free and Studio. The Signature LUT and the One-Click LUT work in any editor that reads .cube files: Premiere Pro, Final Cut Pro, CapCut and more. Not using Resolve? Get the LUTs Only edition.

Do I need advanced experience or Log footage? +

No advanced experience needed — the tutorial walks you through it step by step. Log gives you the most flexibility, but the workflow also adapts to Rec.709 footage.

How do I receive the files? +

Instant download via Lemon Squeezy right after purchase, with free updates for this version.
